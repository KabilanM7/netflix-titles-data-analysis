Netflix Titles Data Cleaning and Preprocessing

Project Overview :
This project focuses on cleaning and preprocessing the Netflix Titles dataset using Python.
To identify and handle missing values, remove duplicate records, and standardize data formats.

Technologies Used :
- Python
- Pandas
- NumPy

Project Files :
1. `clean_data.py` – Python data cleaning program.
2. `netflix_titles.csv` – Original Netflix dataset.
3. `cleaned_data.csv` – Cleaned dataset.
4. `cleaning_summary.md` – Summary of data cleaning operations.
5. `README.md` – Project documentation.

Data Cleaning Steps :
- Identify missing values.
- Handle null values.
- Remove duplicate records.
- Standardize text formats.
- Save the cleaned dataset.

How to Run :

```bash
pip install pandas numpy
python clean_data.py netflix_titles.csv
```
Expected Output :
- cleaned_data.csv
- cleaning_summary.md

Conclusion :
This project demonstrates basic data cleaning and preprocessing techniques using Python and Pandas.
